# RangeReality roadmap

## Shipped to the bench

- Drive mode: signed power gauge, regen peak tracking, learned
  efficiency pace, advisory line
- Charge mode: AC/DC auto-scale, rate-of-charge history, SOC taper,
  time-until-80/100
- Trip log on microSD with wall-clock timestamps
- Service mode: QR setup, Wi-Fi portal, trip viewer
- Hardware-in-the-loop simulator: every release bench-validated
  on real displays before it touches a truck
- All common CYD display variants supported

## Next

- Truck validation drive (pace learning, regen peaks, trip log)
- OTA updates from the service portal
- GPS module (trip endpoints, speed cross-check)
- Public release binaries + web flasher on this repo
- One download that adapts to whichever display you have
- Portrait orientation and additional display themes
